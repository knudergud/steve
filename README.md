# Steve Harrington portfolio

An original, responsive fictional portfolio for Steve Harrington. Built as a static site with semantic HTML, modern CSS, lightweight JavaScript, accessible interaction states, and reduced-motion support.

The site is in `dist/`. GitHub Actions deploys it to GitHub Pages after each push to `main`.

Live site: https://knudergud.github.io/steve/

## Local preview

Open `dist/index.html` in a browser, or serve `dist/` with any static file server.

This is an unofficial fan project created as a design exercise. It is not affiliated with Netflix or the creators of *Stranger Things*.
